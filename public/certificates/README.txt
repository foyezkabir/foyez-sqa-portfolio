Drop the four certificate PNGs in this folder, then set the `image` path on the
matching entry in src/app/components/Certifications.tsx, for example:

    image: "/certificates/istqb-ctfl.png"

The card shows a thumbnail when an image is set and falls back to its icon when
not, so the section looks finished either way.

Suggested filenames:
    istqb-ctfl.png
    cypress-web-automation.png
    iso-27001.png
    business-analysis.png
